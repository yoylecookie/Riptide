How to create a Riptide Playlist

Step 1. Upload assets

go to FileGarden and make a new directory (NO SPACES IN THE NAME), then upload your songs and album covers (1 cover per song)

2. Create a riptide.json

go to Our Json Editor and add the urls of the song files in the Audio URL section, and add the urls of the cover art in the cover URL section

(ex. https://file.garden/user/test/flyhigh.mp3)
(ex. https://file.garden/user/test/flyhighart.png)

3. Upload riptide

download the json file from the editor and import it in the same place you put all of the songs and art, then copy the preview link

(ex. https://file.garden/user/test/riptide.json)

4. Encode

go to Our Encoder and get the code, you can put this code in riptide to play the songs
